# Guía para la Asignatura Estructura de Datos 

> Este repositorio está destinado a explicar las distintas estructuras de datos que se verán en la asignatura. Cuenta también con recursos explicativos y código claro para ver de forma interactiva y práctica cómo se organizan y funcionan dichas estructuras.

---

## Contenido del Repositorio

El material está organizado en 4 bloques principales siguiendo el temario oficial de la asignatura:

### 1. Fundamentos y Memoria (`01_fundamentos/`)
* **Notación Big-O:** Complejidad algorítmica y eficiencia.
* **Tipos de Datos y Contenedores:** Tipos primitivos y abstracción.
* **Memoria en C++:** Punteros (`*`), referencias (`&`), Stack, Heap, `new`/`delete` y `templates`.

### 2. Estructuras Lineales (`02_Estructuras Lineales/`)
* **Vectores y Matrices:** Arreglos estáticos, `std::vector`, matrices y conjuntos de bits.
* **Listas Enlazadas:** Listas simples, dobles, circulares y matrices dispersas.
* **Adaptadores y STL:** Uso de Pilas (Stack), Colas (Queue), Colas de Prioridad, `deque` y `list`.

### 3. Estructuras No Lineales (`03_Estructuras no Lineales/`)
* **Árboles:** Árboles binarios, BST (Árboles Binarios de Búsqueda) y recorridos.
* **Grafos:** Conceptos básicos, representación mediante listas y matrices de adyacencia.

### 4. Algoritmos y Búsqueda (`04_Archivos y Persistencia/`)
* **Iteradores:** Uso y tipos de iteradores en la STL.
* **Algoritmos Estándar:** Búsqueda, ordenación y manipulación de contenedores.
* **Tablas Hash:** Funciones Hash y resolución de colisiones.
