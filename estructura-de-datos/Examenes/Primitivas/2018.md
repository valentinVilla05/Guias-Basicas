Los conjuntos disjuntos pueden usarse para segmentar imágenes, de forma que cada conjunto disjunto representará una zona formada por un conjunto de píxels contiguos de similares características (p.ej. del mismo color). En cada paso el algoritmo toma dos píxels vecinos $p_1$ y $p_2$ y realiza la siguiente operación

```cpp
// Si dos píxels pertenecen a dos conjuntos distintos pero son similares entre sí
if (buscar(p1) != buscar(p2) && similar(p1, p2)) {
    unir(buscar(p1), buscar(p2));
}
```
