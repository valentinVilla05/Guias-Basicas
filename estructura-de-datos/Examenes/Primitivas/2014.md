1. Mostrar el proceso de inserción de los siguientes datos: `7, 2, 9, 14, 5` en dos tablas de dispersión A y B de **tamaño 5** y dispersión por división, donde **A implementa dispersión abierta y B dispersión cerrada con exploración cuadrática**. Agrupar varios pasos cuando sea posible siempre que no perjudique la legibilidad del ejercicio.

> Resolución
* **Datos del ejercicio**

    * **Elementos a insertar**: 7, 2, 9, 14, 5
    
    * **Tamaño de las tablas ($t$**): 5
    
    * **Función Hash base**: $h(x) = x \pmod 5$

### Tabla A: Dispersión Abierta (Encadenamiento)
En la dispersión abierta, si hay colisión simplemente se añade el nuevo elemento a una lista enlazada en la posición correspondiente

**Cálculos del Hash:**

* $h(7) = 7 \pmod 5 = \mathbf{2}$

* $h(2) = 2 \pmod 5 = \mathbf{2}$ (colisiona en la pos 2, se añade a la lista)
* $h(9) = 9 \pmod 5 = \mathbf{4}$$h(14) = 14 \pmod 5 = \mathbf{4}$ (colisiona en la pos 4, se añade a la lista)
* $h(5) = 5 \pmod 5 = \mathbf{0}$

```text
Pos | Lista Enlazada
--------------------
 0  | [ 5 ]
 1  | (vacío)
 2  | [ 7 ] -> [ 2 ]
 3  | (vacío)
 4  | [ 9 ] -> [ 14 ]
```
### Tabla B: Dispersión Cerrada con Exploración Cuadrática
En la dispersión cerrada, los elementos van dentro del vector. Si hay colisión, buscamos la siguiente casilla disponible con la fórmula:$$h(x, i) = (x + i^2) \pmod 5 \quad \text{donde } i = 0, 1, 2, \dots$$

Pasos de inserción:

* **Insertar 7**:
$i=0 \implies h(7, 0) = (7 + 0^2) \pmod 5 = \mathbf{2}$ $\rightarrow$ Libres $\implies$ Guarda 7 en pos 2.

* **Insertar 2**:
$i=0 \implies h(2, 0) = (2 + 0^2) \pmod 5 = \mathbf{2}$ $\rightarrow$ Colisión con el 7$i=1 \implies h(2, 1) = (2 + 1^2) \pmod 5 = \mathbf{3}$ $\rightarrow$ Libre $\implies$ Guarda 2 en pos 3.

* **Insertar 9**:
$i=0 \implies h(9, 0) = (9 + 0^2) \pmod 5 = \mathbf{4}$ $\rightarrow$ Libre $\implies$ Guarda 9 en pos 4.

* **Insertar 14**:
$i=0 \implies h(14, 0) = (14 + 0^2) \pmod 5 = \mathbf{4}$ $\rightarrow$  Colisión con el 9 $i=1 \implies h(14, 1) = (14 + 1^2) \pmod 5 = \mathbf{0}$ $\rightarrow$ Libre $\implies$ Guarda 14 en pos 0

* **Insertar 5**:
$i=0 \implies h(5, 0) = (5 + 0^2) \pmod 5 = \mathbf{0}$ $\rightarrow$ Colisión con el 14 $i=1 \implies h(5, 1) = (5 + 1^2) \pmod 5 = \mathbf{1}$ $\rightarrow$ Libre $\implies$ Guarda 5 en pos 1.


```text

--------------

 1  |    5
 2  |    7
 3  |    2
 4  |    9
```


2. 
a) Implementar la función `vector<T> ABB<T>::InordenNR( )`; capaz de devolver los datos de un árbol ABB en inorden de forma no recursiva en un vector de salida

> Resolución

#### Explicación
El recorrido inorden se realiza como: Izquierda $\rightarrow$ Raíz $\rightarrow$ Derecha

Como no podemos usar recursividad, en estos casos **siempre** debemos usar una pila (**stack**)

1. Desde el nodo actual, bajamos todo lo posible a la izquierda guardando cada nodo en la pila

2. Cuando no podemos bajar más a la izquierda, desapilamos un nodo, guardamos su dato en el vector de salida, y nos desplazamos a su hijo derecho

3. Repetimos el proceso mientras la pila no esté vacía o el nodo actual no sea nulo

> Representación
```
       (20)              Pila (Stack)         Vector Salida
      /    \             ------------         -------------
    (10)   (30)          |   10     |         [ ]
    /  \                 |   20     |
  (5)  (15)              ------------
                          (Bajamos a la izquierda del todo)

  1. Desapilamos 5  ---> Guarda 5            ---> Vector: [5]
  2. Subimos a 10   ---> Desapila y guarda 10 ---> Vector: [5, 10]
  3. Vamos a 15     ---> Pila: [15] -> Guarda ---> Vector: [5, 10, 15]
  4. Subimos a 20   ---> Desapila y guarda 20 ---> Vector: [5, 10, 15, 20]
  5. Vamos a 30     ---> Pila: [30] -> Guarda ---> Vector: [5, 10, 15, 20, 30]
```

> Implementación

```cpp
// Asumimos las estructuras auxiliares básicas (Pila y Vector)
template <typename T>
Vector<T> ABB<T>::InordenNR() {
    Vector<T> resultado;
    Pila<NodoABB<T>*> pila;
    NodoABB<T>* actual = raíz; // Empezamos en la raíz del árbol

    // El bucle continúa mientras queden nodos por procesar en el árbol o en la pila
    while (actual != nullptr || !pila.vacia()) {
        
        // 1. Apilamos todos los nodos del camino hacia la izquierda
        while (actual != nullptr) {
            pila.empujar(actual);
            actual = actual->izq;
        }

        // 2. Procesamos el nodo del tope de la pila
        actual = pila.tope();
        pila.desapilar();

        // 3. Añadimos su valor al resultado
        resultado.insertarFinal(actual->dato);

        // 4. Pasamos a explorar el subárbol derecho
        actual = actual->der;
    }

    return resultado;
}
```


b) Implementar la función `void ListaEnlazada<T>::inserta(Iterador<T> &it1, ListaEnlazada<T> &l2)`; que inserte en la lista simplemente enlazada `*this` en la posición siguiente a la apuntada por el iterador it1, todos los elementos de la lista l2. Supongamos las listas: `*this={10, 20, 30, 40, 50}` y `l2={31, 32, 33, 34}`, apuntando it1 a 30. El resultado tras realizar la operación sería: `*this={10, 20, 30, 31, 32, 33, 34, 40, 50}`. No podrán usarse otras operaciones de la clase ListaEnlazada<T>

> Resolución

#### Explicación

Queremos insertar todos los elementos de l2 justo después del nodo apuntado por `it1`

1. Si la lista l2 está vacía, no se hace nada

2. Localizamos el nodo actual apuntado por it1 (llamémosle `nodoActual`)

3. Guardamos el nodo que le seguía originalmente: `nodoSiguiente = nodoActual->sig`

4. **El siguiente del nodoActual pasa a ser el primer nodo de l2 (l2.cabecera)**

5. Buscamos el último nodo de l2 recorriéndola.

6. **El siguiente del último nodo de l2 pasa a ser nodoSiguiente**

7. Quitamos los punteros de l2 para que sus nodos pertenezcan a `*this`


> Representación

```cpp
Estado inicial:
  *this: [10] -> [20] -> [30] (it1) ----------> [40] -> [50] -> nullptr
  l2:                    [31] -> [32] -> [33] -> [34] -> nullptr

Paso 1: Conectar el nodo 30 al inicio de l2 (31)
  *this: [10] -> [20] -> [30]
                          |
                          v
  l2:                    [31] -> [32] -> [33] -> [34]

Paso 2: Conectar el final de l2 (34) con el resto de *this (40)
  *this: [10] -> [20] -> [30] -> [31] -> [32] -> [33] -> [34] -> [40] -> [50] -> nullptr
```

> Implementación
```cpp
template <typename T>
void ListaEnlazada<T>::inserta(Iterador<T> &it1, ListaEnlazada<T> &l2) {
    // Si la lista l2 a insertar está vacía, no hay nada que hacer
    if (l2.cabecera == nullptr) {
        return;
    }

    // Guardamos el puntero al nodo que apunta actualmente el iterador 1
    Nodo<T>* nodoActual = it1.getNodo(); 

    // Guardamos el nodo que viene después de it1 para no perderlo
    Nodo<T>* nodoSiguiente = nodoActual->sig;

    // 1. El nodo actual ahora apunta al inicio de la lista l2
    nodoActual->sig = l2.cabecera;

    // 2. Buscamos el último nodo de la lista l2
    Nodo<T>* ultimoL2 = l2.cabecera;
    while (ultimoL2->sig != nullptr) {
        ultimoL2 = ultimoL2->sig;
    }

    // 3. El último nodo de l2 apunta al nodoSiguiente que habíamos guardado
    ultimoL2->sig = nodoSiguiente;

    // 4. Si el iterador apuntaba al último nodo original, actualizamos el puntero 'cola'
    if (nodoActual == cola) {
        cola = ultimoL2;
    }

    // 5. Vaciamos l2 ya que sus nodos ahora pertenecen a *this
    l2.cabecera = nullptr;
    l2.cola = nullptr;
}
```
