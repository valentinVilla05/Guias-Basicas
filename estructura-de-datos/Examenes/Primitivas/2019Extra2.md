# Primitivas del Examen 2 de la extraordinaria de 2019

1. Mostrar el resultado de insertar (I) y borrar (B) la siguiente secuencia de datos en un árbol B de orden 3. Realizar todas las operaciones posibles dentro del mismo dibujo.   `I(3), I(10), I(2), I(8), I(1), I(4), I(7), I(5), I(12), B(1), B(8), I(9), B(2)`

> Resolución

1. I(3)
Se inserta 3 en la raíz vacía

```
[ 3 ]
```

2. I(10)
Se inserta 10 en el mismo nodo

```
[ 3 | 10 ]
```

3. I(2)
Al insertar 2, el nodo temporal pasa a tener 3 claves: [2, 3, 10].
Se desborda (overflow): la mediana 3 sube como nueva raíz y se dividen los hijos

```
      [ 3 ]
     /     \
  [ 2 ]   [ 10 ]
```

4. I(8)
8 va a la hoja derecha (es menor que 10)

```
      [ 3 ]
     /     \
  [ 2 ]   [ 8 | 10 ]
```

5. I(1)
1 va a la hoja izquierda

```
        [ 3 ]
       /     \
  [ 1 | 2 ]  [ 8 | 10 ]
```

6. I(4)4 busca la hoja derecha [8 | 10]. Queda [4, 8, 10] $\rightarrow$ Se divide: 8 sube al nodo raíz
```
        [ 3 | 8 ]
       /    |    \
  [ 1 | 2 ] [ 4 ] [ 10 ]
```

7. I(7)
7 entra en el nodo central [4]
```
         [ 3 | 8 ]
       /     |     \
  [ 1 | 2 ] [ 4 | 7 ] [ 10 ]
```

8. I(5)
5 busca la hoja central [4 | 7], produciendo [4, 5, 7].
La mediana 5 sube a la raíz. Como la raíz [3 | 5 | 8] se desborda, la mediana 5 sube creando una nueva raíz

```
           [ 5 ]
         /       \
      [ 3 ]     [ 8 ]
     /     \   /     \
  [1|2]   [4] [7]   [10]
  ```

9. I(12)
12 va a la hoja más a la derecha [10]

```
           [ 5 ]
         /       \
      [ 3 ]     [ 8 ]
     /     \   /     \
  [1|2]   [4] [7]   [10 | 12]
```

10. B(1)
Se elimina 1 de la hoja [1 | 2]. El nodo queda con [2], sin provocar subdeficiencia

```
           [ 5 ]
         /       \
      [ 3 ]     [ 8 ]
     /     \   /     \
  [ 2 ]   [4] [7]   [10 | 12]
```

11. B(8)
Se borra 8 (nodo interno). Se reemplaza por su sucesor en inorden (10).
El nodo hoja derecho pierde el 10 y se queda con [12]

```
           [ 5 ]
         /       \
      [ 3 ]     [ 10 ]
     /     \   /      \
  [ 2 ]   [4] [7]    [12]
```

12. I(9)
9 entra en la hoja [7]
```
           [ 5 ]
         /       \
      [ 3 ]     [ 10 ]
     /     \   /      \
  [ 2 ]   [4] [7 | 9]  [12]
```
13. B(2)Se borra 2 de la hoja [2].   
1. La hoja queda vacía (Underflow).
2. Pide prestado a la hoja hermana [4] a través de la raíz local [3]: 3 baja a la hoja y 4 sube al padre

```
           [ 5 ]
         /       \
      [ 4 ]     [ 10 ]
     /     \   /      \
  [ 3 ]   [-] [7 | 9]  [12]
```

Resultado: 

```
           [ 5 ]
         /       \
      [ 4 ]     [ 10 ]
     /     \   /      \
  [ 3 ]   [ ] [7 | 9]  [12]
```
