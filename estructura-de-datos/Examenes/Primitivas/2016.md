2. Mostrar la evolución de un heap tras la realización de las siguientes operaciones (mostrar sólo la representación compacta en el vector de soporte): `push(8), push(7), push(1), push(2), push(9), push(5), pop(), pop(), push(3)`. Menor valor numérico implica mayor prioridad

> Resolución:

1. `push(8)`
Se inserta el primer elemento en la raíz
> Vector: [8]

2. push(7)
Se inserta al final (índice 1) y reflota (7 < 8)

> Vector: [7, 8]
3. `push(1)`
Se inserta al final (índice 2) y reflota (1 < 7)

> Vector: [1, 8, 7]

4. `push(2)`
Se inserta al final (índice 3, hijo izq de 8) y reflota (2 < 8)

> Vector: [1, 2, 7, 8]

5. `push(9)`
Se inserta al final (índice 4, hijo der de 2). Como 9 > 2, no reflota.

> Vector: [1, 2, 7, 8, 9]

6. `push(5)`

Se inserta al final (índice 5, hijo izq de 7) y reflota (5 < 7)

> Vector: [1, 2, 5, 8, 9, 7]

7. `pop()`
Elimina el mínimo (1). Se coloca el último elemento (7) en la raíz y se hunda (flota hacia abajo con el menor de sus hijos: 2 vs 5 $\rightarrow$ 2).

* **Reemplazo inicial**: [7, 2, 5, 8, 9]
* **Hundir 7**: Intercambio con 2 $\rightarrow$ [2, 7, 5, 8, 9]
* **Hundir 7**: Comparar 7 con sus hijos (8 y 9) $\rightarrow$ No cambia más.

> Vector: [2, 7, 5, 8, 9]

8. `pop()`

Elimina el mínimo (2). Se coloca el último elemento (9) en la raíz y se hunda (menor hijo de 9 es 5)

> Vector: [5, 7, 9, 8]

9. `push(3)`
Se inserta al final (índice 4, hijo dcho de 7) y reflota (3 < 7 y luego 3 < 5)

> Vector: [3, 5, 9, 8, 7]

```cpp
template<typename T>
bool ABB<T>::arbolPerfecto(unsigned h);
```


> Resolución


```cpp
template <typename T>
bool ABB<T>::arbolPerfecto(unsigned h){
    return esPerfectoAux(raiz,h);
}

template<typename T>
bool ABB<T>::esPerfectoAux(Nodo *n, unsigned h){
    if(!n)
        return false;

    if(h==0)
        return true;

    // Para h > 0, ambos hijos deben existir y cumplir el criterio para h - 1
    return esPerfectoAux(n->izq, h - 1) && esPerfectoAux(n->dcha, h - 1);
}
