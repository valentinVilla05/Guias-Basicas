1. Dibujad el estado de un árbol B de orden 3 tras insertar (I) y borrar (B) la siguiente secuencia de datos: `I(103), I(430), I(202), I(27), I(120), I(40), I(250), I(233), B(430), I(62), B(103)`

> Resolución: 

**Reglas para un Árbol B de orden 3:**

* **Máximo de claves por nodo**: $m - 1 = 2$ claves
* **Máximo de hijos por nodo**: $m = 3$ hijos
* **Mínimo de claves por nodo (salvo la raíz)**: $\lceil m/2 \rceil - 1 = 1$ clave
* **División (Split)**: Cuando un nodo alcanza 3 claves, la clave mediana sube al padre

**1. Insertar 103 y 430**

```
[ 103 | 430 ]
```

**2. Insertar 202**
El nodo se llena [103 | 202 | 430]. Se divide: la mediana 202 sube como nueva raíz

```
       [ 202 ]
      /       \
  [ 103 ]   [ 430 ]
```

**3. Insertar 27 y 120**
* 27 entra a la izquierda de 202 $\rightarrow$ [27 | 103]
* 120 entra en [27 | 103 | 120], que se llena. La mediana 103 sube a la raíz

```
          [ 103 | 202 ]
         /      |      \
    [ 27 ]   [ 120 ]   [ 430 ]
```

**4. Insertar 40 y 250**
* 40 entra en el nodo izquierdo [27 | 40]
* 250 entra en el nodo derecho [250 | 430]

```
             [ 103 | 202 ]
           /       |       \
     [ 27 | 40 ]  [ 120 ]  [ 250 | 430 ]
```

**5. Insertar 233**
Entra en el nodo derecho [233 | 250 | 430]. Se llena y se divide: la mediana 250 sube a la raíz.

La raíz [103 | 202 | 250] también se llena y se divide: la mediana 202 sube como nueva raíz global

```
                 [ 202 ]
               /         \
        [ 103 ]           [ 250 ]
       /       \         /       \
  [ 27 | 40 ] [ 120 ] [ 233 ]   [ 430 ]
```

**6. Borrar 430**
430 está en una hoja simple [430]. Se elimina directamente sin dejar el nodo vacío

```
                 [ 202 ]
               /         \
        [ 103 ]           [ 250 ]
       /       \         /       \
  [ 27 | 40 ] [ 120 ] [ 233 ]    [ ]
```
Como el nodo queda subdesbordado, redistribuye con el hermano izquierdo [233]: baja 250 y sube 233

```
                 [ 202 ]
               /         \
        [ 103 ]           [ 233 ]
       /       \         /       \
  [ 27 | 40 ] [ 120 ] [ ]       [ 250 ]
```

**7. Insertar 62**
Entra en el nodo de la izquierda [27 | 40], que se llena [27 | 40 | 62]. Se divide: 40 sube al padre [103]

```
                      [ 202 ]
                   /           \
            [ 40 | 103 ]        [ 233 ]
           /     |     \        /       \
      [ 27 ]   [ 62 ] [ 120 ] [ ]    [ 250 ]
```


**Estado final del arbol**
```
                  [ 202 ]
                /         \
           [ 40 ]         [ 233 ]
          /      \       /       \
     [ 27 ]    [ 62 ] [ 120 ]   [ 250 ]
```


2. a) Implementar la función `ListaEnlazada<T> ListaEnlazada<T>::inversa (void);` que devuelva otra lista simplemente enlazada cuyos datos tengan los datos en orden inverso al de la lista original

```
template <typename T>
ListaEnlazada<T> ListaEnlazada<T>::inversa(void) {
    ListaEnlazada<T> listaInversa;
    Nodo<T>* actual = cabecera;
    while (actual) {
        listaInversa.insertarInicio(actual->dato);
        actual = actual->siguiente;
    }
    return listaInversa;
}
```

b) Implementar la función `vector<T> ABB<T>::PreordenNR();` capaz de devolver los datos de un árbol ABB en preorden de forma no recursiva

Los ejercicios que nos piden hacerlos sin recursividad debemos hacerlos con pila:

```cpp
template <typename T>
class Pila {
private:
    class NodoPila {
        T dato;
        NodoPila* sig;
        NodoPila(T d, NodoPila* s = nullptr) : dato(d), sig(s) {}
    };
    NodoPila* tope;

    public:
    Pila() : tope(nullptr) {}

    ~Pila() {
        while (!vacia()) desapilar();
    }

    bool vacia() const {
        return tope == nullptr;
    }

    void apilar(T d) {
        tope = new NodoPila(d, tope);
    }

    T desapilar() {
        if (vacia()) return nullptr;
        NodoPila* aux = tope;
        T dato = aux->dato;
        tope = tope->sig;
        delete aux;
        return dato;
    }
};


template <typename T>
std::vector<T> ABB<T>::PreordenNR() {
    std::vector<T> resultado;
    if (raiz == nullptr) return resultado;
    Pila<NodoABB<T>*> pila;
    pila.apilar(raiz);
    while (!pila.vacia()) {
        NodoABB<T>* actual = pila.desapilar();
        resultado.push_back(actual->dato);
        if (actual->derecha != nullptr) {
            pila.apilar(actual->derecha);
        }
        if (actual->izquierda != nullptr) {
            pila.apilar(actual->izquierda);
        }
    }
    return resultado;
}
```
