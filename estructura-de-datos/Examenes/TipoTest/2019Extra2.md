# Tipo test Examen 2 Extra 2019

**1. [F]** En el siguiente código C++ se produce una fuga de memoria o memory leak:
```cpp
int *k = new int[100];

for (i = 0; i <= 100; ++i) { k[i] = 0; }

...

delete[] k;
```

> **Explicación**: Explicación: No hay desbordamiento ni fuga de memoria porque delete[] se ejecuta correctamente; el error es un acceso fuera de límites en el bucle (i <= 100)

**2. [F]** La implementación normal de un vector dinámico implementa una reducción del tamaño físico tamf a la mitad cuando el tamaño lógico taml cae por debajo de tamf/2

> **Explicación**: El tamaño físico se reduce a la mitad cuando el tamaño lógico cae al $33\%$ ($taml \cdot 3 < tamf$) 

**3. [V]** Una clase que implementa una lista circular no incluye un puntero al nodo cabecera de la misma, al contrario que las listas simple y doblemente enlazadas

> **Explicación**: Al ser circular, cualquier nodo permite acceder a toda la lista, por lo que no requiere obligatoriamente un nodo cabecera especial como las lineales

**4. [V]** Transferir todos los nodos de una lista simplemente enlazada $l1$ al final de otra lista enlazada $l2$ requiere tiempo $O(n)$ (nota: $l1$ queda vacía tras esta operación)

> **Explicación**: Sin un puntero directo al final de $l2$, se debe recorrer $l2$ hasta el último nodo en tiempo $O(n)$ para enlazar $l1$

**5. [V]** Un árbol binario es un grafo normalmente dirigido, conexo y libre de ciclos, donde el grado de salida de todos los nodos es igual o inferior a 2

> **Explicación**: Un árbol binario es un grafo acíclico y conectado donde cada nodo tiene a lo sumo grado de salida 2 (hijo izquierdo y derecho)

**6. [V]** El cambio de posición de los nodos en una rotación simple de un árbol AVL se implementa con únicamente 4 asignaciones de punteros

> **Explicación**: Una rotación simple ajusta exactamente 4 punteros para actualizar los enlaces entre los tres nodos involucrados y el padre

**7. [F]** En dispersión abierta puede ocurrir que un dato no quede guardado en la posición indicada inicialmente por la función de dispersión

> **Explicación**: En dispersión abierta (listas enlazadas exteriormente), las claves colisionadas se guardan en la lista de la posición calculada inicialmente

**8. [V]** Sea Complejo una clase que implementa número complejos de la forma $(a + ib)$ tal como se muestra a continuación. La declaración de un conjunto de números complejos mediante la declaración STL `set<Complejo> complejos`;

```cpp
class Complejo {
public:
    float real, imag;

    Complejo(float real, float imag):
        real(real), imag(imag) {}
};
```

> **Explicación**: Es una declaración sintácticamente válida para std::set, aunque requerirá definir el operador < para ordenar sus elementos en la práctica

**9. [ V ]** El borrado lógico de un registro en un fichero de datos puede hacerse con 3 accesos si hay que mantener una lista de registros borrados o únicamente 1 si no existe dicha lista

> **Explicación**: Si hay lista de borrados se requiere leer el registro, actualizar punteros de la lista y escribir (3 accesos); sin lista solo se marca el registro como borrado (1 acceso)

**10. [V]** La profundidad de todas las hojas de un árbol B es la misma.

> **Explicación**: Los árboles B crecen hacia arriba desde la raíz, lo que garantiza un equilibrio perfecto donde todas las hojas están en el mismo nivel
