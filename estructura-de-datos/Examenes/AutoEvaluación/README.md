# Preguntas de Autoevaluación de Platea

Son las preguntas del apartado de Preparación de exámenes suelen entrar bastante en los tipo test de enero, por lo que es aconsejable echarles un vistazo. Hay que tener en cuenta que las preguntas no son las mismas para todos: aunque se trate del examen del mismo tema, el sistema varía y a cada uno le pueden salir preguntas completamente distintas. Para ampliar las preguntas que falten nos la podeis mandar por la página y las meteremos en el banco de preguntas
