## Consideraciones

Los ejercicios son bastantes importantes para el examen, muchas de las preguntas teóricas de seleccionar Verdadero o Falso (donde no hay que explicar nada) pueden llegar a caer en el examen e incluso las de programar una función para un determinado tipo de dato

Es importante saber hacerlos y también sirve como repaso para recordar como se programa cada cosa dependiendo de la estructura de datos que nos pidan

## Estructura del Examen

**1. Tipo Test (2 puntos)** 

> UNA MAL QUITA UNA BIEN 

**2. Dibujar (1,5 puntos)** (como la de ArbolesAVL ejercicio 1)

**3. Primitiva (1,5 y 1,5 puntos)** 

> Quiere decir que son las de programar una función en C++ (**SIN STL**) (SIEMPRE CAE O **ARBOLES** O **LISTAS ENLAZADAS**)

**4. UML (3,5 puntos) CON STL**

> IMPORTANTE: Si no se llega al mínimo esperado entre el ejercicio 3 y 4 el examen está suspenso
