# 3. Clasificación de los Sistemas Operativos
## 3.1 Respecto al Modo de Trabajo del Usuario
Los sitemas operativos se pueden clasificar según la forma en que el usuario intecartúa con ellos durante la ejecución de las tareas

* **En línea / Interactivos:** Existe comunicación constante en tiempo real entre el usuario y el sistema : (ej: procesadores de texto)

* **Fuera de línea / Lotes (Batch):** El usuario entrega una lista de atareas y se desentiende por completo; no vuelve a intervenir hasta que el proceso finaliza


### Ejecución por lotes en Linux (Shell Scripts):
Aunque Linux es un sistema interactivo, permite la **ejecución por lotes** mediante **shells scripts**: archivos de texto que contienen una secuencia de órdenes que el sistema ejecuta automáticamente sin intervención humana

**1. Compromiso de rendimiento (Trade-off)**
* **Ventaja**: Desarrollo más rápido (no requiere compilación , ideal para automatizar tareas)

* **Desventaja**: Ejecución más lenta que la de un programa compilado 

**2. Entorno de Ejecución: Subshell vs Shell Actual**
Al lanzar un script se abre un proceso hijo (**subshell**) independiente. Cualquier cambio hecho en ese proceso aislado (como cambiar de carpeta con `cd`) desaparece al terminar la ejecución

* **Ejecución normal (Subshell aislado)**
```bash
$ script.sh
```
* **Ejecución en el Shell actual (Sin subshell):**
```bash
$ . script.sh
```

*(El símbolo . o la orden source ejecutan el script directamente en tu sesión, conservando los cambios como el directorio de trabajo)*

## 3.2. Respecto al Número de Usuarios
* **Monousuario:** Permite el acceso a un único usuario a través de un único terminal (ej. MS-DOS, CP/M)

* **Multiusuario (Multiacceso):** Permite a varios usuarios interactuar simultáneamente mediante múltiples terminales. Requiere imperativamente un modelo de tiempo compartido (ej. UNIX, AS/400, MVS)

## 3.3. Respecto al Propósito
Los sistemas operativos se clasifican según la variedad de tareas que pueden realizar y el entorno para el que han sido diseñados


**1. Sistemas de Propósito General**

Diseñados para ejecutar una amplia variedad de aplicaciones y atender a múltiples usuarios. Se dividen principalmente en:

* **Sistemas por Lotes (Batch):** Procesan grandes volúmenes de trabajos acumulados sin interacción directa del usuario

* **Sistemas de Tiempo Compartido:** Asignan pequeños turnos de CPU a cada usuario o programa para dar la sensación de uso simultáneo e interactivo

**2. Sistemas de Propósito Específico (Embebidos / Empotrados)**
Diseñados exclusivamente para controlar dispostivos concretos (alarmas, electrodomestricos..), con interfaces de usuario minimas o inexistentes

* **Sistemas de Tiempo Real (RTOS):** Procesan datos de sensores y responden a eventos externos dentro de **límites de timepo estrictos**. Si se excede el tiempo libre, el sistema falla

* **Sistemas Multimedia**: Optimizados para la reproducción continua de audio y video en tiempo web evitando pausas o saltos en la transmisión

* **Sistemas para Dispositivos Móviles y de Mano**: Adaptados a hardware limitado (pantallas pequeñas, baterias..)
