# 3. Clasificación de los Sistemas Operativos
## 3.1 Respecto al Modo de Trabajo del Usuario
* **En línea / Interactivos:** El usuario interactúa directamente con el sistema durante la ejecución de las tareas (ej. entornos de desarrollo, procesadores de texto, tiempo compartido).

* **Fuera de línea / Lotes (Batch):** Se introduce un trabajo y el usuario no tiene contacto alguno con él hasta que finaliza la ejecución completa.

### Ejecución por lotes en Linux (Shell Scripts):
* Un **shell script** es un archivo de texto con un conjunto de órdenes que el intérprete interpreta y ejecuta en lote sin intervención humana.
* **Proceso:** Al ejecutar un script se crea un nuevo proceso.

* **Compromiso (Trade-off):** El desarrollo en lenguajes interpretados es más rápido (sin etapa de compilación), pero su tiempo de ejecución es mayor comparado con lenguajes compilados.

## 3.2. Respecto al Número de Usuarios
* **Monousuario:** Permite el acceso a un único usuario a través de un único terminal (ej. MS-DOS, CP/M)

* **Multiusuario (Multiacceso):** Permite a varios usuarios interactuar simultáneamente mediante múltiples terminales. Requiere imperativamente un modelo de tiempo compartido (ej. UNIX, AS/400, MVS)

## 3.3. Respecto al Propósito
* **Propósito General:** Diseñados para una gran variedad de aplicaciones y usuarios
    * **Lotes (Batch)**
    * **Tiempo de COmpartido**
* **Propósito Específico (Embebidos /Empotrados)** : Sistemas dedicados a monitorizar y gestionar hardware concreto (automoción, robótica, telefonía). Tienen interfaces muy reducidas o inexistentes
    * **Sistemas de Timepo Real (RTOS)**: Procesan eventos e información de sensores en plazos de tiempo estrictos (control industrial, aviación, simuladores)
    * **Sistemas Multimedia**: Gestionan audio/vídeo requiriendo restricciones de tiempo y rendimiento continuo para evitar cortes
    * **Sistemas de Mano / Móviles**: (Smartphones, Smartwatches, PDAs): Embebidos especiales con recursos limitados (pantallas reducidas, CPUs lentas y menor memoria).
