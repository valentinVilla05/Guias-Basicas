# 1.4. Generación del Sistema (SYSGEN)
El proceso **SYSGEN** (SYStem GENeration) consiste en configurar o adaptar un SO genérico a la configuración específica de hardware de una máquina concreta.

1. **Recopilación de información:** Se obtiene leyendo un fichero, mediante un cuestionario al operador o sondeando (probing) el hardware instalado (tipo de CPU, RAM disponible, periféricos y parámetros del SO como búferes o algoritmos)

2. **Generación del ejecutable:**

    * **Modificación del código fuente:** Se reconfigura el código fuente y se recompila completamente.

    * **Montaje modular:** Se seleccionan bibliotecas precompiladas y tablas para enlazar el SO final.

    * **Basado en tablas:** El código contiene todas las opciones y la selección se hace en tiempo de ejecución.
