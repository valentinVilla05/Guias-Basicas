# 1.4. Generación del Sistema (SYSGEN)
Proceso mediante el cual un Sistema Operativo genérico (distribuido en una imagen ISO, DVD o memoria USB) **se configura y adapta al hardware** específico de una máquina concreta

### Fase 1: Recopilación de Información
El programa SYSGEN detecta o solicita los datos de la máquina mediante un archivo de configuración, un cuestionario al operador o un escaneo directo del hardware (probing). Se determina:
* **Hardware**: Tipo de CPU, cantidad de memoria RAM y dispositivos periféricos conectados

* **Opciones del SO**: Tamaño y número de búfers, algorítmos de planificación y número máximo de processos permitidos

### Fase 2: Métodos de Generación del Ejecutable
Una vez obtenida la información, se utiliza uno de estos 3 métodos para construir el sistema:

**1. Modificación y compilación del código fuente:** Se adapta el código fuente original con los parámetros obtenidos y se recompila el SO desde 0

**2. Montaje de módulos precompilados**: Se seleccionan bibliotecas de código ya compiladas y se enlazan mediante tablas paraa formar el ejecutable final

**3. selección por tablas en tiempos de ejecución**: Todo el código del SO viene instalado por defecto, y los parámetros seleccionados se activan dinámicamente cuando el programa arranca
