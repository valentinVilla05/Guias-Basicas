# 1.5. Inicio del Sistema Operativo (Arranque / Bootstrapping)
Proceso mediante el cual el hardware localiza, carga e inicia la ejecución del kernel en la memoria principal

## 1.5.1. Etapas del Proceso de Arranque

1. **Encendido / Reset:** La CPU recibe un evento de reconfiguración y carga el registro de instrucción con una dirección fija en memoria de solo lectura (ROM/EEPROM)

2. **Firmware (BIOS / UEFI)**
    * Realiza un diagnóstico del hardware (**POST**)
    * Inicializa registros de la CPU, controladores E/S y la memoria RAM
    * Localizar el dispositivo de arranque
3. **Cargador de Arranque (*Bootstrap Loader*)**
    * **Paso 1:** Un pequeño cargador ubicado en el Bloque 0 (Boot Block) del disco o partición de arranque es leído y ejecutado por el firmware

    * **Paso 2:** Este programa lee y carga el programa de arranque complejo (ej. GRUB, LILO) o directamente el kernel completo en la memoria RAM para iniciar su ejecución

**Nota sobre el almacenamiento del SO**
**Dispositivos de mano:** Cargan todo el SO directamente desde la memoria ROM/Flash.

**Propósito General:** El firmware contiene el código inicial de diagnóstico/lectura, mientras que el kernel completo reside en el disco.
