# 1.5. Inicio del Sistema Operativo (Arranque / Bootstrapping)
Es el proceso mediante el cual la computadora localiza, carga en la memoria RAM e inicia la ejecución del kernel del sistema operativo tras encender la máquina

## 1.5.1. Etapas del Proceso de Arranque

1. **Encendido / Reset:** Al pulsar el botón de encendido, la CPU recibe una señal de reinicialización (reset event) y carga su registro de instrucción con una dirección fija almacenada en memoria no volátil (ROM/EEPROM)

2. **Firmware (BIOS / UEFI)**
    * **POST (Power-On Self-Test):** Ejecuta diagnósticos para comprobar que componentes como la RAM, tarjeta gráfica y discos funcionen correctamente

    * **Inicialización**: Prepara los registros de la CPU, controladores de dispositivos y la memoria principal

    * **Búsqueda:** Identifica el dispositivo que contiene el sistema operativo (disco duro, SSD, USB)

3. **Cargador de Arranque (*Bootstrap Loader*)**
    * **Paso 1 (Cargador primario):** El firmware lee y ejecuta un código de tamaño reducido situado en una posición fija del disco llamada bloque de arranque (Boot Block o Bloque 0)

    * **Paso 2 (Gestor de arranque completo):** Este código carga en memoria un gestor de arranque más complejo (como GRUB o LILO en Linux), el cual se encarga de localizar el kernel, cargarlo en la memoria RAM e iniciar su ejecución

## Tipos de almacenamiento del SO según el dispositivo
* **Dispositivos de mano / embebidos (Smartwatches, IoT):** Suelen mantener todo el SO almacenado directamente en memoria ROM o Flash debido a su tamaño reducido y hardware sencillo

* **Sistemas de propósito general (PC, Servidores):** El firmware almacena únicamente las instrucciones iniciales de chequeo y lectura, mientras que el SO completo reside en el disco duro o SSD. Esto permite actualizar o cambiar el sistema operativo sin modificar el chip físico del equipo
