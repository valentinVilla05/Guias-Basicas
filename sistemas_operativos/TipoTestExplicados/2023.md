1) ¿Cuál de estos sistemas informáticos **NO** se puede dar?
a) Sistema por lotes no multiprogramado
b) Sistema multiusuario de tiempo compartido
c) Sistema de tiempo compartido no multiprogramado.
d) Sistema de tiempo real y tiempo compartido.

> Respuesta: C 
Para que un sistema sea de **tiempo compartido**, la CPU debe alternar rápidamente los processo de varios usuarios para dar la ilusión de que estos se ejecutan simultáneamente, por ende tienen que ser **multiprogramados** (mantener varios programas o procesos cargados en memoria al mismo tiempo)

2) La estructura de diseño operativo que consiste en crear un núcleo con una funcionalidad
básica y que los servicios de alto nivel se ejecuten como componentes en el espacio del
usuario se llama:
a) Estructura en Niveles.
b) Máquina Virtuales
c) Monolíticos.
d) Micronúcleo

> Respuesta: D
La estructura de **micronúcleo** deja dentro del kernel solo lo mínimo e imprescindible para que el sistema funcione (gestión básica de memoria, procesos y comunicación). Todo lo demás se saca feura y se ejecuta como programas comunes en el **espacio de usuario**

3) En un sistema de gestión de memoria de paginación con memoria virtual
a) El número de páginas que están cargadas en memoria de cada proceso es siempre
proporcional al número total de páginas que tiene dicho proceso.
b) Un proceso provoca como mínimo tantos fallos de página como número de
páginas tenga
c) Un proceso cuyo número de páginas es mayor a otro proceso, puede provocar
menos fallos de página
d) Si ejecutamos varias veces un mismo proceso, siempre producirá el mismo número
de fallos de página.

> Respuesta: C
El número de página no depende solo del tamaño del proceso, sino de la cantidad de **marcos de memoria asignados** y del **principio de localidad** (cómo y con que frecuencia accede a sus páginas). Un proceso más grande que repite en bucle la misma instrucción apenas generará fallos, mientras que uno pequeño que acceda continuamente a posiciones de memoria dispersas provocará muchos más

máximo de elementos que puede tener el “conjunto de trabajo" con una ventana 🔼 de 5
a) 3
b) 4
c) 5

5) En una tabla de páginas invertida hay una entrada por cada:
a) marco de memoria principal.
b) página lógica de un proceso
c) por cada entrada de la TLB
d) por cada página virtual alojada en la memoria secundaria

> Respuesta: A
En las tablas de páginas convencionales, hay una entrada por cada $página virtual$ de un proceso (lo que hace que la tabla sea muy grande). En una **tabla de páginas invertidas**, existe **una sola entrada por cada marco de memoria física (RAM)** real que tiene el sistema, independientemente de cuántos processos o páginas virtaules existan

6) En un sistema de gestión de memoria paginado al disminuir el tamaño de página manteniendo los tamaños de espacio físico y lógico, aumenta: 
a) El número de entradas de la tabla de páginas y también el tamaño de cada entrada
b) La tabla de página no cambia en nada y mantiene su tamaño inicial
c) El número de entradas de la tabla de páginas pero cada entrada tendrá el mismo tamaño
d) El tamaño de entradas de la tabla de páginas pero no su número

> Respuesta: C
$\text{Número de entradas} = \frac{\text{Tamaño espacio de direcciones lógicas}}{\text{Tamaño de página}}$ 
Al reducir el tamaño de página (denominador), aumentan las páginas totales y por tanto el número de entradas. El tamaño de cada entrada guarda la dirección del marco físico, lo cual **no depende** de que la página sea más pequeña

9) Si la dirección física es de 38 bits, la dirección lógica de 52 bits y el temario de página de

a) 2^14
b) 2^38
c) 2^24
d) 2^16

11) Cuando se produce un fallo de página, el proceso que provoca el fallo
a) Pasa al estado "Suspendido"
b) Pasa el estado "Bloqueado"
c) Pasa al estado "En ejecución"
d) Pasa al estado "Preparado"

> Respuesta: B

13) ¿Cuántos procesos se crean cuando se ejecuta el siguiente código incluyendo el proceso inicial que ejecuta el programa principal?

```C
main() {
    int i, pid, otropid;
    pid = fork();
    if (pid)
        pid = fork();
    else
        otropid = fork();
}
```
a) 3   
b) 4   
c) 5   
d) 6

> Respuesta: B
1. Compienza el **Proceso P0**
2. `pid=fork()`; -> **P0 crea P1**
3. `if (pid)`:
    * P0 (donde `pid != 0`) entra en el if y ejecuta `pid = fork();`, creando a **P2**
    * P1 (donde `pid == 0`) entra en el else y ejecuta `otropid = fork();`, creando a **P3**

15) En un sistema con un algoritmo de planificación prioridad al más corto se puede producir un cambio de proceso cuando:

17) Supongamos un sistema de gestión de memoria con segmentación con una memoria principal de 64 KB. Un proceso emite las siguientes direcciones lógicas (0,4526), (3,400). A continuación se muestra tabla de segmentos ¿Cuáles serán las direcciones físicas correspondientes?

| Nº segmento | Base | Longitud | 
| 0 | 0 | 7230 | 
| 1 | 16384 | 8191 | 
| 2 | 32768 | 1024 | 
| 3 | 8192 | 356 | 

a) 7230 y 8592   
b) 7230 y 356   
c) 0 y 8192   
d) 4526 y la dirección (3,400) no es válida 

> Respuesta: D

1. Para una dirección lógica $(\text{segmento}, \text{desplazamiento})$:
* Debe cumplirse que el $\text{desplazamiento} < \text{longitud del segmento}$. Si no se cumple, se genera un fallo por violación de segmento (trap)
* Si es válida: $\text{Dirección Física} = \text{Base} + \text{desplazamiento}$

2. Dirección $(0, 4526)$:
* Segmento 0: $\text{Base} = 0$, $\text{Longitud} = 7230$
* ¿$4526 < 7230$? Sí, es válida.
* $\text{Dirección Física} = 0 + 4526 = 4526$

3. Dirección $(3, 400)$:
* Segmento 3: $\text{Base} = 8192$, $\text{Longitud} = 356$
* ¿$400 < 356$? No ($400 \ge 356$), el desplazamiento excede la longitud del segmento, por lo que la dirección no es válida.

18) Se realizan las solicitudes a disco: 100, 58, 70, 89, 125, 12, 36 (en ese orden). La cabeza del disco está en el cilindro 96 moviéndose hacia el cilindro 0.   
a) Si se utiliza el algoritmo SCAN son atendidas 100,58,70,89,125,12,36   
b) Si se utiliza el algoritmo SCAN son atendidas 89,70,58,36, 12, 100, 125   
c) Si se utiliza el algoritmo FIFO son atendidas: 89,125 12,36,100, 58,70   
d) Todas las afirmaciones son FALSAS   

> Respuesta: B
Algoritmo SCAN: La cabeza está en la posición 96 moviéndose en dirección descendente hacia el cilindro 0. Atiende todas las solicitudes pendientes en esa dirección en orden descendente y, al invertir el sentido, atiende las solicitudes en orden ascendente:
* Hacia el cilindro 0: $89, 70, 58, 36, 12$
* Tras dar la vuelta: $100, 125$
* Orden final de atención por SCAN: $89, 70, 58, 36, 12, 100, 125$

20) Si se desea acceder al bloque número $n$ de un fichero que reside en disco, es cierto que:   
a) En un sistema MS-DOS (únicamente con la FAT cargada en memoria) supondrá realizar n accesos al disco   
b) En un sistema de ficheros con asignación contigua, teniendo en memoria cargada su entrada del directorio, supondrá realizar a accesos a disco

22) Suponga que un proceso emite una dirección lógica (2,18004) utilizando un modelo de gestión de memoria basado en segmentación paginada, con páginas de 4096 bytes [la imagen dice 4098 por un error tipográfico común, pero en potencia de 2 se refiere a 4096 = 4 KB]. A esa dirección lógica le corresponde la dirección física:
a) 26126   
b) 22105   
c) 40104   
d) 13908

> Respuesta: D
a) $26126 \rightarrow 26126 \pmod{4096} = 1558 \neq 1620$
b) $22105 \rightarrow 22105 \pmod{4096} = 1625 \neq 1620$
c) $40104 \rightarrow 40104 \pmod{4096} = 3240 \neq 1620$
d) $13908 \rightarrow 13908 = (3 \times 4096) + 1620 = 12288 + 1620 = 13908$

23) Un proceso que se ejecuta sobre una máquina UNIX ejecuta una llamada al sistema para crear un enlace duro sobre un fichero desde un directorio. Se crea una nueva entrada en un directorio pero debido a un fallo no se llega a incrementar el contador de enlaces. ¿Produce esto alguna incoherencia en el sistema de ficheros?   
a) Sí, el contador de enlaces es menor que el número de entradas del directorio y puede llegar a liberar todos sus bloques cuando aún no se han borrado todas las entradas de directorio   
b) No, ninguna, cuando se recorra el árbol de directorios se cambia el valor de contador de enlaces del nodo-i por el valor calculado.   
c) Sí, el contador de enlaces es mayor que el número de entradas del directorio y no se podría eliminar el nodo-i.   
d) Sí, el contador de enlaces es menor que el número de entradas del directorio y no se podría eliminar el nodo-i. 

> Respuesta: A
Si la entrada del directorio existe (hay 2 nombres apuntando al i-nodo), pero el contador de enlaces se queda en 1 (es decir, el contador es menor que el número real de entradas del directorio):
>* Cuando el usuario borre uno de los archivos, el contador pasará de 1 a 0.
>* Como el contador llega a 0, el sistema de ficheros asumirá que ya no hay más referencias al archivo y liberará el i-nodo y sus bloques de datos, dejando la otra entrada de directorio apuntando a un i-nodo liberado/corrupto

25) Si tenemos un sistema con memoria virtual mediante paginación por demanda que cuenta con 16 marcos y que se está ejecutando un único proceso que ocupa 17 páginas, es cierto que:

a) El proceso generará un fallo de página cada vez que acceda a memoria.   
b) Con toda seguridad se acabará produciendo hiperpaginación.   
c) Todas las afirmaciones son FALSAS.   
d) El sistema será incapaz de ejecutar el proceso al no haber suficiente memoria principal.   

> Respuesta: C
a) Falsa. Si accede repetidamente a las páginas que ya están en los 16 marcos en memoria, no generará fallos en cada acceso.
b) Falsa. 16 marcos son casi el 100% del tamaño total del proceso (17 páginas). No habrá thrashing o hiperpaginación severa a menos que el patrón de acceso alterne aleatoriamente la 17ª página constantemente, pero no "con toda seguridad".
d) Falsa. La memoria virtual permite justamente ejecutar procesos más grandes que la memoria física asignada.
