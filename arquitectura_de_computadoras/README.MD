# Guía de apoyo para las prácticas de Arquitectura de Computadores

Esta guía es simplemente para apoyarse a la hora de practicar o prepararse las prácticas semanales de la asignatura Arquitectura de computadores.

Recomendamos NO copiar los ejercicios directamente sino pararse a entender qué y como hacer cada cosa paso a paso.

Recordatorio de que para estas prácticas se necesita tener impresa la hoja de instrucciones:
